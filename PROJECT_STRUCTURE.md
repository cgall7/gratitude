# Project Structure: Pollinate

Generated from the tree, not from a plan. Every directory below exists.

```text
pollinate/
├── assets/                # icon.png, spiral-mark.png (fonts load from @expo-google-fonts)
├── src/
│   ├── components/        # Reusable UI (StripedBee, HexShape, PressableScale, FeedCard, …)
│   ├── constants/         # theme.js (Sunbeam tokens), motion.js (SPRINGS/DURATIONS), copy
│   ├── contexts/          # React contexts
│   ├── navigation/        # MainTabs + tabBarLayout
│   ├── screens/           # TodayTab, HoneycombTab, RecapTab, Onboarding, CoreRitual, Account, …
│   ├── services/          # EntryStore (local AsyncStorage), HoneycombStore + supabase (social)
│   └── utils/             # combGeometry, themeTagger, date helpers
├── supabase/migrations/   # Postgres schema + RLS policies
├── App.js                 # Root entry point
├── app.json               # Expo config — name, slug, iOS bundle id
└── package.json
```

## Notes

- **There is no `ios/` or `android/` directory, and that is not an omission.**
  This is a managed Expo app; native projects are generated by `expo prebuild`
  and are not checked in. Run `expo start --ios`, never `npm run ios` /
  `expo run:ios` unless you specifically want a prebuild.
- **iOS only for now** (2026-08-13 direction). The `android` block in
  `app.json` is dormant, not active work.
- The screen-lock native module (`src/services/NativeLockInterface.ts`,
  `PollinateLock`) is a **JS-side stub** — FamilyControls/ManagedSettings need
  a dev build and an Apple entitlement, neither of which exists yet. Nothing
  calls it.
- Design spec: `GUIDES/GRATITUDE_DESIGN_SYSTEM_V1.md` (Sunbeam v1). Product
  direction: `PLANS/POLLINATE_*.md`.
